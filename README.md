# REAL HR — Real Education AI HR Platforması

Real Education tálim orayı ushın arnawlı islep shıǵılǵan zamanagóy AI Recruitment & Onboarding (Kadrlar tańlaw hám adaptaciya) sisteması.

![Real HR Logo](/public/real-logo.jpg)

## 🌟 Tiykarǵı Múmkinshilikler

- **AI Intervyu:** Google Gemini AI arqalı kandidatlardıń kásiplik hám pedagogikalıq bilimlerin onlayn sáwbetlesiw arqalı bahalaw.
- **Telegram Mini App Integraciyası:** Telegram bot arqalı bir basıwda platformaǵa kiriw hám arza tapsırıw.
- **Onboarding Portal:** Jumısqa qabıllanǵan jańa komanda aǵzaları ushın jeke adaptaciya kabineti, AI mentor, birinshi háptelik wazıypalar hám SOP qaǵıydaları.
- **HR & CEO Basqarıw Paneli:** Vakansiyalar, kandidatlar bazası, analitika hám kadrlar rejelestiriw modulları.

## 🚀 Texnologiyalar

- **Frontend:** Next.js (App Router), Tailwind CSS, Framer Motion, Lucide Icons
- **Backend:** Next.js API Routes, Prisma ORM
- **Database:** PostgreSQL (Supabase / Neon)
- **AI:** Google Generative AI (Gemini)
- **Integraciya:** Telegram Bot API
